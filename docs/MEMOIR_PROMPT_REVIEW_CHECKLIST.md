## PR 1：转写与事实准确性

实现已完成，独立 review 发现的基线保护与年龄问答分支已补修。运行时逻辑：重复整理以最近人工编辑、多路校对稿或原始识别为基线，预览和并发检查仍以当前显示版本为准；校对上下文限定为目标讲述之前；批量尊重项目档位，离线三档均校对后润色。旧 AI 整理稿不参与多 ASR 证据比对。版本裁剪保护最近人工基线和当前离线校对基线；批量手改也计入离线重识别的人工保护。历史离线记录未独立保存校对稿时，只能使用最早尚存的整理稿，无法重建已经丢失的历史校对内容。主动询问改为当前周岁；出生年/属相等仍算已问年龄资料并保留问答供去重，往事中的年龄不算。分类失败时保留既有待确认计数和问答，不再用关键词猜测；持续失败可能少问资料，但不会绕过提问上限，之后仍能提取用户主动提供的资料。人物提取只保留实际消费的身份字段，删除未使用的 unclear 字段及补问生成说明。成功生成不再经正则删词和压平段落，降级时保留原述措辞。

验证：本机 Linux/ParadeDB 全量后端 Ruff 与 1785 项测试通过（最终补修工作树记录 `20261025T025827Z-28e2af38`）；小程序 `npm ci`、类型检查及 900 项测试通过。合成讲述 DeepSeek Flash 回放 19 个样本 × 三档，57/57 片段检查通过并逐篇核对；另检查出生年份、明确周岁、历史年龄、多子女及含糊代词 5 个提取样本。Review 后追加 4 个问答样本 × 三档（12/12）、5 个多 ASR 分歧/单路/缺原文样本、8 个年龄提问分类样本；逐项检查输出。独立 review 的全部结论已处理，最终完整本机回归通过。

缩减规则后回放发现局部年份/姓名更正和跨记录编辑存在退化，因此保留三个短例子；其余示例移至现有 `memoir_self_correction.json`。样本结果不是所有输入均正确的保证；不接入自动“事实核验通过”标记。

## PR 2：素材组织与上下文

实现覆盖初始规划、增量归类、小节候选设计/逐条分配/整节合并、全目录重整、两级摘要、话题匹配及语义索引。章为大主题、小节为小主题，允许主题相关的多件事共处一节。共用提问解析优先采用同会话的有效父消息（尊重人工关联，不受录音顺序限制）；人工取消关联时不补配，否则取早于回答的最近有效提问，跨越连续回答与不需回答的提示；转写、离线 ASR、资料提取及成书链路共用该规则。问题只用于理解明确回答，不能把问题中的猜测、复合问题的含糊同意或编辑确认变成事实。小节摘要和目录缓存签名包含实际提问，重整写入前复核提问是否变化。

长素材在预算允许时展示全文，受限时取首中尾摘录，保留完整素材归属清单并提示证据范围。章节摘要明确只收到小节摘要，不把摘要疑义直接升级为阻塞事实冲突。摘要与检索逐项保留否定、确定程度和转述来源，无必要信息时不补问、不生成索引。

验证中实际模型发现资料混入章节、短回答受书名误导、年份不确定扩散到年龄、转述来源只写在解释中四类退化，已对应修正。DeepSeek Flash 的 11 个合成样本覆盖上述各生成分支，逐项核对最终输出；本机隔离 Linux/ParadeDB 全量后端 Ruff 与 1823 项测试通过（最终补修工作树记录 `20261025T054818Z-8b0cccd1`）；独立 review 已完成，全部结论已处理。

补修覆盖提问文字、人工关联和解除关联变化后的转写预览/单条/后台/离线写回保护，初始及增量归类断点、人物补答、资料与人物 reading 缓存及名册过滤。最终写入统一按结构、素材、问答的顺序锁定实际依赖；人物补答各分支逐条提交释放锁。小节重整按实际 JSON 中的问题、回答与编号共同计算概览及分批预算；预算不足以保留最小有效概览时明确拒绝。新增回归覆盖跨数据库会话修改提问、旧预览拒绝、归类重新考虑、资料重读、人物名册失效、锁顺序与 80 条长提问/短回答分批。部署按用户新要求延后至四个 PR 全部完成。

## PR 3：成书与改稿质量

正文与相关小节判断使用配对提问，提问文字进入整章、小节及素材快照签名；最终保存锁住素材和对应问答。事实来源明确区分素材版本、当前人工正文、用户事实更正及 AI 编辑建议。全书与小节修改思路保留独立用户原话，后续反馈与执行继续传入，计划确认不升级其事实地位；全书计划签名也涵盖这些原话。

成书文案只请求本次目标的字段，长章正文使用预算内全文或首中尾，逐字引语允许显式留空。空引语经过保存、后续文案编辑、无关章节更新及重复重装不会被旧默认值恢复。书名与导语尊重专题和部分人生范围；全书审阅明示只收到当前正文，不反复追问记不清的信息，也不要求补全可选身份或文案。六种插画风格共用事实边界与分散摘录说明。

独立 review 的两条空引语生命周期问题已修复并复核。DeepSeek Flash 11 个合成场景（含三档正文）逐项核对；回放发现的重复追问、未知性别代词及“记不清”被改成未记录的问题已收紧并重跑。本机隔离 Linux/ParadeDB Ruff 与全部 1853 项后端测试通过（最终工作树记录 `20261025T062732Z-74ab9a68`，已纳入 main `245846c9`）。部署延后至四个 PR 全部完成。

PR 3 合并后补修：配对提问变化而人工正文已编辑时，实际模型不能稳定区分旧问答解释与人工事实更正。因此明确保留待核对状态，不自动写新稿或推进问答签名；用户可在现有手工编辑器逐节修订，或显式重新生成整章。保存绑定编辑器打开时的正文版本及素材签名，未核对小节继续保留旧证据，旧版人工稿所有小节继续受保护。全书正文修订的预览和采纳也保留显式空封底引文。独立 review 发现的恢复死循环、过期保存与 legacy 多节保护缺口均已修复并复核。最终已同步 main `008f5371`，本机 Linux/ParadeDB Ruff 与全部 1879 项后端测试通过（记录 `20261025T072642Z-c8de8ac5`）；小程序 npm ci、类型检查与全部 920 项测试通过。部署仍延后至全部 Prompt PR 完成。
