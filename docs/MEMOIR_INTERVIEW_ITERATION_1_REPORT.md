# 访谈 Agent 第一轮候选对比

2026-10-21。结论：`grounded_v1` 保留在实验分支，本轮不采用为线上默认。
它减少了部分无依据评价，但仍有事实前提错误，并在本次冻结对比中新增一条忽略否定更正的失败。
以下质量判断均为 Agent 初审，人工审核完成数仍为 0。

## 实验范围

沿用[基线记录](./MEMOIR_INTERVIEW_BASELINE_REPORT.md)和冻结选择：
24 份开发/产品输入、14 份评测输入，各版本每例一次；模型、temperature、上下文窗口、最大输出和策略模式相同。
候选只在普通 AI 访谈中补充事实边界，明确访谈员的问题不是讲述者事实，
礼貌承接不补写个人属性，问题前提不添经历，“不知道/没有证据”保留为未知。
成书补访实际 Prompt 与 baseline 完全相同；其随机措辞差异不归因于本轮改动。

候选在执行评测前固定，评测后未继续调 Prompt。76 次回应、74 次影子策略调用全部完成，
原始输入、实际 Prompt、代码补丁、模型及用量均保留，没有只挑最好的一次。
实验代码已保存为[提交 2f209dcd](https://github.com/kolafish/pawtale/commit/2f209dcd1f124a062d5f1dcf25e7c64fa2a20cc1)，
分支为 `codex/interview-agent-grounded-candidate`；基于 Pawtale `ecbeeee0`，
新增 Prompt 版本为 `memoir_voice_interviewer_stream_turn_v10/grounded-v1`。

14 条评测合计只有 3 个真实来源分组。109、152 曾在此前的数据标注审阅中查看，
因此这批数据只能称为冻结对比集，不能称为完全未见的盲测。所有结果均不代表泛化或真实用户效果。

## 质量对比

五维各 0–2 分，先按源分组平均；评分者为同一 Agent，未与人工校准，以下数值仅用于诊断。

| 数据轨道 | baseline | grounded_v1 | 来源组数 |
| --- | ---: | ---: | ---: |
| 开发：真实访谈 | 8.250 | 8.250 | 4 |
| 开发：合成困难 | 9.417 | 9.334 | 2 |
| 评测：真实访谈 | 9.500 | 10.000 | 2 |
| 评测：合成困难 | 8.666 | 8.834 | 2 |

开发与产品场景中的严重失败样本由 4 条变为 2 条：健康状况和长期心理的无依据断言消失，
但年龄推断人生经历、措辞中的隐含前提仍需检查；其他普通问法也有退化。
评测中的严重失败各 2 条，分布发生变化，不能用总分上涨表示通过。

| 样本 | baseline / 候选的发现 |
| --- | --- |
| `interview-zh-118` | baseline 预设离开军乐团；候选改为预设向遇到的教授学习，事实关系仍无依据 |
| `interview-zh-163` | baseline 将“律师展示材料”改为“律师看完材料”；本次候选保持了展示这一动作 |
| `interview-zh-170` | 两版都把“查过资料”推进为“已经查到资料/线索” |
| `interview-zh-204` | baseline 问查询过程；候选在用户刚说没有找到资料后仍问“查到的情况”，新增忽略更正的失败 |
| `product-completion-done` | 两版都保留既有的结束话语 / listen 动作不一致；本轮未改变这条路径 |

失败已记录到本地逐例评分；118、170、204 及相关人物组应进入后续回归。
下一轮若调整候选，不能再把本轮已查看的评测组当作未使用的测试组；需另留新的来源/人物组。

## 延迟和用量

| 运行 | 回应 / 影子调用 | 首段文本中位数 | 估算费用 |
| --- | ---: | ---: | ---: |
| baseline 开发 | 24 / 23 | 0.860 秒 | 0.017195 元 |
| 候选开发 | 24 / 23 | 0.817 秒 | 0.014686 元 |
| baseline 评测 | 14 / 14 | 0.866 秒 | 0.010100 元 |
| 候选评测 | 14 / 14 | 0.834 秒 | 0.010509 元 |

总计估算 0.052490 元，无调用失败或未知用量项。耗时受网络影响，费用受输出长度和 provider 缓存命中影响；
这些单次采样数字不证明候选降低延迟或成本。TTS、真机停顿与打断体验需后续聚焦验证。

## 交付与采用决定

实验提交中的 `InterviewConfig.prompt_variant` 和离线 `--prompt-variant` 支持 baseline / grounded_v1，
评测保留实际生效 Prompt 版本，成书补访即使选择该候选也仍记录原版本。
主分支只合入本轮报告；线上继续使用原 Prompt，没有开放客户端切换或新增线上状态。

本轮验证表明，笼统补充事实边界并未稳定解决动作角色、查询结果状态和最新否定的使用问题。
下一轮应优先验证这些区别的上下文表达，并由人工核对评分尺度，再决定采用；不据平均分自动发布。

本地审阅入口：

- `output/interview-agent/compare-dev/review.md` 与 `ratings.jsonl`：24 份开发输入的匿名成对材料。
- `output/interview-agent/compare-eval/review.md` 与 `ratings.jsonl`：14 份冻结输入的匿名成对材料。
- 两个目录中的 `ratings.agent.jsonl` / `summary.agent.json`：明确标为 Agent 的逐例初审与统计。
- `baseline-dev`、`candidate-dev`、`baseline-eval`、`candidate-eval`：完整输入、运行记录及代码补丁。

复跑候选须使用上述实验提交，并在原命令中指定 `--prompt-variant grounded_v1`，每次使用新输出目录。
主分支不提供该候选开关；后续实验可从保存的提交继续，所有已查看评测样本按回归用途处理。
本机首次 smoke 的代理格式失败也保留在单独目录；真实模型运行由仅清除该进程代理环境后完成。
