# 老余口述｜分享产品设计

日期：2026-10-25。状态：待开发的目标设计，不代表当前线上能力；按[开发计划](MEMOIR_SHARING_IMPLEMENTATION_PLAN.md)分批落地。

## 1. 产品原则

用户看到满意内容，使用同一个「分享给好友」按钮发送；好友免登录阅读、收听和观看。采用固定默认内容，不提供分享配置面板，不要求先生成链接。分享只开放当前对象，正文更新自动同步到旧链接。

## 2. 默认分享内容

| 对象 | 默认内容 | 好友体验 |
| --- | --- | --- |
| 故事 | 一个已保存小节的标题、完整正文、已入书配图 | 读故事、听 AI 朗读 |
| 单章 | 章名、本章全部正文、已入书配图 | 读本章、看小节目录、听本章 |
| 整书 | 书名、封面、已有署名、前言、当前入书章节及配图、后记 | 看目录、按章阅读和收听 |
| 视频 | 当前成片、标题、封面、已有讲述人署名 | 看原声视频、字幕，使用现有播放和倍速控制 |

- 视频不附带整书入口；故事、单章不展示其他未分享内容，也不提供跳转整书的入口。
- 仅使用书稿已有署名，不自动采用账户实名；排除原始访谈、内部整理记录、待确认事项、未入书素材。AI 配图保留生成标识。
- 故事复用现有小节正文，不另写分享稿。文字朗读明确标注「AI 朗读」；原声分享先复用视频，不另建原声卡片。
- PDF、TXT、视频文件保留为导出能力，放在次要操作。在线链接可停止，已经发出的文件无法撤回。

## 3. 统一分享 UI

沿用小程序现有暖纸色、深色文字和陶红强调色，复用 `app.wxss` 的颜色、字体、圆角、阴影与大字模式。统一视觉与操作语义，文字阅读和视频播放器保留各自适合的布局。

| Before（当前） | After（目标） |
| --- | --- |
| 「分享阅读页」「发送阅读页」「转发给好友」叫法不同 | 主按钮统一为「分享给好友」，同一图标、字号、颜色和按压反馈；旁边用「本故事／本章／整本书／本视频」说明范围 |
| 单章分享藏在更多操作，文字分享需要先生成链接 | 单章标题区直接分享；故事正文末尾直接分享；整书、视频沿用现有主操作位置；首次点击完成准备，再点同一按钮发送；已准备好时直接发送 |
| 分享面板混合生成、更新、重建和撤销操作 | 主界面只保留分享按钮；作者的「预览分享内容」「停止分享」收进已有更多操作；停止后仍保留作者自己的内容 |
| 阅读与视频的反馈区域、推广入口各自设计 | 内容末尾统一「点赞 · 我也记得这件事 · 分享给好友」操作区；「我也想讲故事」为更低层级入口 |
| 作者预览与好友实际所见不一致 | 预览使用同一内容与阅读布局，只增加「好友将看到这些内容」提示，不展示编辑能力 |
| 图片、按钮和加载状态存在页面差异 | 共用卡片与状态规范：未分享、准备中、可分享、失败重试、已停止；发送准备失败保留当前内容，不把用户送入无关页面 |

正文默认 32rpx、大字模式 36rpx，阅读行高 1.8；卡片圆角、页面边距、按钮最小触控区分别沿用现有 28rpx、32rpx、88rpx token。长标题正常换行；图片保留比例，视频按片形适配；轻量按压反馈，不增加入场动画和 UI 依赖。

微信原生分享无法可靠等待较长的异步准备，因此未授权时先在同一按钮显示准备状态，成功后提示再点该按钮发送；失败仍在原处重试，不打开原生发送页，不增加生成链接入口。

分享卡片统一「标题＋已有封面或配图」；无图使用品牌默认封面。摘要只取当前分享正文，不生成夸张标题，不要求用户选模板。

## 4. 阅读与播放界面

| 页面 | 从上到下的内容 |
| --- | --- |
| 故事 | 标题、署名 → 听故事 → 正文和配图 → 统一反馈区 |
| 单章 | 章名、署名 → 听本章 → 可展开的小节目录 → 正文和配图 → 统一反馈区 |
| 整书 | 简洁封面、署名 → 开始／继续阅读 → 章节目录 → 按章阅读、上一章／下一章 → 统一反馈区 |
| 视频 | 视频播放器 → 标题、署名 → 统一反馈区；播放结束保留片尾画面与重播 |

全书按章展示，不堆成长页面；在本机记住阅读和收听位置。新版中原位置不存在时回到对应章首或目录。朗读准备、失败均不阻塞正文；只播放与当前分享正文匹配的音频。预览可随时打开，不是发送前的必经步骤。

## 5. 链接与更新

- 作者明确点击分享才开启授权；进入页面、阅读或预览不自动公开。取消微信发送不会撤销已开启的分享，可在更多中停止；不宣称取消后已经发送成功。
- 文字新版本保存并整理完成后，旧链接自动指向新版。生成中或失败时继续展示上一版完整内容，不要求作者确认更新。
- 整书随当前入书章节更新；单章、故事限定原对象。主动删除、移出或收回的内容立即退出相应分享；如不能安全保留旧版，暂停该对象，不能继续暴露已移除内容。
- 视频固定对应当前成片，重新制作产生新视频，不静默替换旧成片；分享状态与整书完全独立。
- 新分享默认长期有效；停止后旧链接及对应媒体访问失效。再次开启使用新链接，旧链接与旧片尾码不恢复；新发视频的片尾码与新链接一致。
- 存量有效链接迁移时保留地址；已过期或撤销的链接不自动恢复。好友可转发同一范围，不因此扩大权限。
- 失效页区分作者停止、内容删除、存量链接过期与网络失败；只有可恢复错误提供重试，并提供返回首页入口。服务端确认分享失效后，好友端清除该页已载入的正文和媒体。

## 6. 好友回应

保留现有点赞和作者反馈；新增「我也记得这件事」，支持文字、语音，提交时再完成必要登录。回应只对提交者和作者可见，不设公开评论区。

作者通过现有首页反馈区域进入回应详情，选择「收为补充素材」后进入既有素材整理流程；保留回应人、对应故事与原始声音来源，不直接覆盖书稿。重复操作不重复入库。

## 7. 完成标准与边界

四类分享入口、卡片、预览、状态和反馈视觉一致；一个按钮使用默认内容；文字旧链接自动更新；视频不通向整书；停止后链接及媒体不可继续请求；好友读完可回应，作者确认后才入素材。

本轮不建设独立分享中心、公开社区、模板市场或复杂权限设置，不调整无关页面布局。既有架构文档仍说明当前实现，由各实现 PR 同步更新对应章节。
