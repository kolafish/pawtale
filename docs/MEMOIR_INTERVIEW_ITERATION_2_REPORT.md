# 访谈 Agent 全量分集与第二轮 Prompt 实验

2026-10-22。本轮保留开发 / 评测划分，比较 baseline、grounded_v1 和新增的 grounded_v2 / v3 / v4。
开发集优选为 grounded_v3；评测集上 v4 的均分略高，v3 的严重问题标记略少，两版仍有新增退化，本轮均不替换线上 baseline。
本文分数为模型初评，不是人工金标；不与第一轮的小样本 Agent 分数混比。

## 范围与冻结

- interview-data `7120a0fedc3144b03feaa18d775be28dc063cc9b`，v3.1，共 208 条有效样本：开发 116、评测 92；2 条隔离记录不使用。
- 开发集：真实访谈 86、自述续谈 18、合成困难 12，16 个划分组；另跑 8 个产品场景回归，不混入外部数据均分。
- 评测集：真实访谈 56、合成困难 36，10 个划分组，与开发分组无交叉。自述续谈仅在开发集。
- 上轮已经查看的 14 条评测样本属于 `voa-tong`、`voa-xi`、`wn-huang` 三组；这三组本轮合计 37 条。其余 7 组 55 条单独列出，不把同组其他窗口冒充未见来源。
- 只依据开发样本修改 Prompt。全部版本及评分规则在北京时间 2026-10-22 08:46:58 冻结，之后执行评测，不再根据评测结果调 Prompt。
- 生成模型 `deepseek-flash`、temperature 0.72、autonomous、shadow 策略，每例每版一次；保留线上上下文窗口和 token 上限。产品补访的实际 Prompt 在各版中相同，其措辞差异不归因于本轮优化。

共 1080 次主实验回应（5 × [116 + 8 + 92]）。原始输入、实际 system/user prompt、控制动作、用量、失败、源码补丁和冻结哈希保存在本地 `output/interview-agent/iteration-2/`。

## 三次开发迭代

| 版本 | 改动 | 开发样本依据 |
| --- | --- | --- |
| baseline | 当前线上原 Prompt | 作为固定比较起点 |
| grounded_v1 | 第一轮在 user prompt 末尾追加四条事实边界 | 保留原候选，本轮重新全量采样 |
| grounded_v2 | 分开核对主体、动作、对象与结果；保留更正，其余已知信息不改写 | v1 仍把遇到教授当作跟教授学习；年龄仍触发无依据评价 |
| grounded_v3 | 在 v2 上要求沿最新已知细节展开，限制自动跳到未讲述的“后来” | v2 仍预设离开军乐团、后来放下难受等后续变化 |
| grounded_v4 | 将约束整理为回应顺序并移到 system prompt，要求一个开放问题、检查已答信息 | v3 出现“信寄到学校”等具体细节预设、二选一或连续两问 |

完整实验实现及各版原文：[实验提交 6eaa2e1a](https://github.com/kolafish/pawtale/commit/6eaa2e1a3e4a5ab19a9cf44ee5467be4ef518bfd)，分支 `codex/interview-prompt-iteration-2`。
代码只在实验分支，线上未启用这些候选。并发执行和批量模型评分复用已有 Agent、模型客户端、评审包及 Rating 校验，没有另建访谈实现。

## 评分口径

正式比较使用同一冻结的 `deepseek-v4-pro`，thinking 开启、temperature 0；每个样本的五版回答随机标为 A–E，隐藏版本名。
裁判分别看到每版实际 system prompt 和 prompt，先列未支持的事实前提，再给承接、价值、事实依据、边界、不重复五项各 0–2 分。
轨道内先按来源组求均值，再对来源组等权平均；严重失败候选数另列，不能被总分抵消。

预检曾使用不带 thinking 的初始裁判，对 248 个开发回应给分过宽，漏掉健康断言和师生关系等前提错误。
这些分数保留在 `review-dev-baseline/`、`review-dev-grounded_v1/`，不用于最终比较。
修改评分规则后，在 5 个开发样本上核对了 10 份回答；这是 Agent 复核，不是人工校准。最终五版重新统一评分，未混用新旧裁判结果。

模型严重失败标签仍可能过严或漏判；Agent 抽查单独写入 `audit.agent.jsonl`，不选择性覆盖模型分数。人工完成数仍为 0。

## 结果

按来源组等权，满分 10 分：

| 版本 | 开发真实访谈 / 86 | 开发自述续谈 / 18 | 开发困难 / 12 | 评测真实访谈 / 56 | 评测困难 / 36 |
| --- | ---: | ---: | ---: | ---: | ---: |
| baseline | 8.053 | 8.935 | 9.083 | 7.769 | 8.806 |
| grounded_v1 | 8.689 | 8.335 | 9.417 | 8.247 | 9.083 |
| grounded_v2 | 8.495 | 8.621 | 9.500 | 8.650 | 9.583 |
| grounded_v3 | 9.169 | 8.290 | 9.250 | 8.790 | 9.333 |
| grounded_v4 | 8.988 | 8.508 | 9.250 | 8.879 | 9.389 |

开发真实访谈、自述、困难轨道分别为 13、3、2 组；评测真实、困难分别为 10、6 组，合成变体与原始来源共享分组，不能把这些组数简单相加。

模型标记的严重问题样本数（每例至多计一次，**待人工确认，包含可能的误报**）：

| 版本 | 开发数据 / 116 | 普通产品场景 / 6 | 成书补访 / 2 | 评测数据 / 92 |
| --- | ---: | ---: | ---: | ---: |
| baseline | 26 | 2 | 1 | 24 |
| grounded_v1 | 16 | 0 | 2 | 18 |
| grounded_v2 | 24 | 0 | 2 | 15 |
| grounded_v3 | 10 | 0 | 1 | 9 |
| grounded_v4 | 13 | 0 | 1 | 10 |

查看评测分数前，仅按完整开发结果选定 v3：普通访谈与产品场景的严重标记合计最低（10），真实访谈分组均分最高（9.169）。选择记录保存于 `selection.dev.json`。
但 v3 的自述续谈得分低于 baseline，说明这一改动并非各场景全面改善。
评测中 v4 的真实访谈均分略高于 v3（8.879 对 8.790），v3 的严重标记总数略少（9 对 10）；不据此回头修改 Prompt 或改写开发选择。

剔除上轮已查看的三个来源组后，剩余 55 条包含 37 条真实访谈、18 条困难样本：

| 版本 | 其余 7 组真实访谈 / 37 | 其余 3 组困难 / 18 | 严重标记 / 55 |
| --- | ---: | ---: | ---: |
| baseline | 7.837 | 8.889 | 15 |
| grounded_v1 | 8.139 | 9.278 | 12 |
| grounded_v2 | 8.739 | 9.611 | 10 |
| grounded_v3 | 8.539 | 9.278 | 8 |
| grounded_v4 | 8.898 | 9.500 | 6 |

v4 在这部分来源上的表现更好，开发优选与这部分评测并不完全一致。每例仅采样一次、模型裁判尚未人工校准，不能认定存在稳定优胜版本。

更正样本另按阶段列分（评测各 6 例、6 组，仍非长期记忆测试）：

| 版本 | 即时承接更正 | 短窗口保持更正 |
| --- | ---: | ---: |
| baseline | 7.333 | 8.833 |
| grounded_v1 | 8.500 | 9.333 |
| grounded_v2 | 9.000 | 9.833 |
| grounded_v3 | 9.667 | 9.500 |
| grounded_v4 | 9.000 | 9.667 |

Agent 复核确认了 v3 的评测退化：`interview-zh-133` 把相邻两句话拼成“名片上写着香港足球发源地”，`interview-zh-168` 把“查过资料”当成“查到第一份资料”。这些例子在 baseline 本次输出中未被模型标成严重问题。
也存在裁判过严的情况：例如 `interview-zh-046` 的“当时跟谁说过吗”可以理解为询问是否向人说过，不能仅凭此确认编造。模型原始分数完整保留，Agent 的异议单列，不选择性改分。

**采用决定：保留 v3、v4 为后续人工复核候选，本轮不上线。**先核对事实前提与拒绝边界，再用新的来源组和多轮对话验证；本轮评测结果已查看，若据此再调参，应将相关数据作为回归集，另留新评测数据。

## 运行与费用

主实验 1080 次回应、1075 次影子策略调用均完成，无调用失败；正式裁判 216 次调用完成了 1080 份评分，无未知用量项或失败。预检另有 1 次回应、1 次影子调用及 254 次裁判调用，全部保留。
按应用计价模块估算：主实验生成及策略约 0.833 元，正式评分约 43.786 元，预检与裁判核对约 1.422 元，总计约 **46.041 元**。主要开销来自离线思考模式裁判，不是线上访谈成本；此数值不是 provider 账单。
不同运行并发数为 2–8，受网络与缓存影响，本轮不据首段文本耗时宣称线上延迟改善。没有执行 TTS 或真机语音验证。

本地总表为 `comparison.json`，费用为 `costs.json`，冻结文件为 `freeze.json` 和 `frozen.code.patch`。

## 可核对的开发反例

`interview-zh-118` 的输入只说明在上海的军队学校学习半年、在那里遇到上海音乐学院的一位教授：

| 版本 | 本次回应中的关键前提 | Agent 核对 |
| --- | --- | --- |
| baseline | 后来到了上海音乐学院那边 | 把教授所属机构当作讲述者到过的学校 |
| grounded_v1 | 那半年主要跟他学了些什么 | 遇见不等于存在师生关系 |
| grounded_v2 | 怎么从军乐团转到别的方向 | 输入没有说明已经发生转向 |
| grounded_v3 | 那次相遇是怎么个情形 | 沿已讲事实开放询问 |
| grounded_v4 | 在上海那半年跟陆教授学习 | 又出现未经确认的师生关系 |

但 v3 在 `interview-zh-095` 中把“收到父亲的信、全班传阅”推成“信寄到学校”，同样不成立。
这些例子说明效果并非随版本号或约束长度单调改善，平均分上涨也不代表所有事实边界已解决。
