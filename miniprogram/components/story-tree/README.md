# 故事树

首页的故事树是产品主视觉：先展示会随讲述成长的树和最多三个代表性主题标签，主题与故事总数
同时作为「查看全部」入口，在同一张卡内展开完整主题列表；讲述入口紧随其后，「我的书」保持为
独立成果入口。主题列表统一显示故事数量，不在首页暴露更底层的回忆素材计数。`story` 使用
`StoryViewData`，由宿主调用纯函数
`storyViewData(snapshot)` 转换；`largeText` 由宿主在页面显示时同步用户设置。

组件只渲染输入并发送事件，不读取账号、请求接口、轮询、导航或修改传入状态。首页负责账号、
项目、授权、讲述和增长提醒等状态。小节及素材细节只在章节工作台展示，首页不展开这些内部层级。

| 事件 | detail | 宿主行为 |
| --- | --- | --- |
| `openprojects` | 无 | 切换当前故事本 |
| `openchapter` | `{ chapterId }` | 打开对应主题的章节工作台 |
| `openbook` | 无 | 打开可读书稿或书稿整理入口 |
| `opentranscripts` | 无 | 打开全部回忆 |
| `voiceedit` | 无 | 打开共享语音编辑入口 |
| `focusgrowth` | `{ top }` | 仅响应用户「看看变化」，用视口坐标定位主题 |

有主题且可打开书稿时，树图左下角显示「翻开整本书」角标，点击仍落在树上。`showBookHint` 由宿主
按用户是否从首页打开过书稿决定，为真时在树下多显示一行提示；大字模式下同时压低树图，保持讲述
入口在首屏。

`heroAction` 和 `afterHero` 是命名插槽。宿主用前者放置接着讲与讲新故事入口，用后者放置成长
成果反馈和声纹授权，不在组件里复制语音状态机。

组件使用 `apply-shared` 样式隔离接收 `app.wxss` 的 UI 基础样式与主题变量，自身样式不向宿主
输出。根节点显式携带大字模式标记。按钮与可点击行保留至少 44px 的点击区域，只对按压相关属性
做短时过渡，并在系统减少动态效果时停用成长动画。

首页调用 `focusGrowth(chapterId)` 时，组件会先展开完整主题列表，再测量现有主题行并发出位置
事件；不存在的目标不跳转。普通刷新不改变滚动位置。`growthAnimating` 只用于本次可见期间新
收到的事件，首屏、重复刷新和重新进入不重放。界面出现提醒、播放动画和定位均不代表用户已
确认；确认仍由宿主调用后端接口。

树图由 `story-growth-stage.ts` 统一选择：无主题为阶段 1；有主题后按 3 个主题 / 3000 字进入阶段 3，
按 5 个主题 / 10000 字进入阶段 4；同时达到 5 个主题和 10000 字才进入阶段 5。字数只合计当前
章节正文，不使用可读状态或全书状态加速成长。五张阶段图依次为种子、萌芽、幼树、长出枝丫和
完整大树，使用首页专用压缩资源；主题枝叶和增长提醒图同样放在 `assets/story-tree/`。

开发者工具组件 Object 属性中的嵌套数组会成为以索引为键的对象，模板不依赖其 `length` 或循环
索引的数值类型。树周围只显示前三个代表性主题，点标签直接打开对应主题；完整主题列表默认收起，由组件本地的「查看
全部」切换，不回写宿主快照。
